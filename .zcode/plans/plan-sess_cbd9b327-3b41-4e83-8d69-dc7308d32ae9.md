# LOREFORGE — Full Base Game Build Plan

**Goal:** transform the current skeleton (2,150 lines, no input, no gameplay) into a complete, playable voxel sandbox RPG — Minecraft-class base game — with survival, crafting, mining, building, mobs, combat, structures, quests, sound, modding, and multiplayer. Every phase lands working code, tests, and **real** screenshots from an in-repo harness (ending the docs-only "evolution" pattern permanently).

**Ground rules for every phase:** (1) each loop must change code and add/keep tests green — markdown-only commits are banned; (2) every claim gets a screenshot produced by the actual game via the new headless/offscreen capture system; (3) STATE.md/BACKLOG.md updated to match only what's verifiably done.

## Architecture (target)

- **lf_engine** — windowing, wgpu renderer: depth buffer, texture-atlas pipeline, opaque + transparent passes, sky/sun/moon/clouds, fog, block-outline, held-item viewmodel, first/third-person camera, F2 screenshot capture, offscreen headless render mode (`--headless --scene X --out Y` for real this time).
- **lf_voxel** — block registry (data-driven `BlockDef`: hardness, tool, light, transparency, drops), chunk columns 16×256×16, world + chunk manager, meshing with per-face textures + smooth lighting/AO + transparency, block entities (chest/furnace/sign), corrected region persistence.
- **lf_worldgen** — multi-noise terrain with all biomes reachable (elevation-aware), caves (3D noise), ore veins by depth, trees/features, structures, water/lava, seeds, world types (normal/superflat/amplified).
- **lf_game** — player entity + physics (AABB vs voxels), survival stats, hunger/food, damage/death/respawn, items/tools/armor/durability, crafting + smelting + the existing smithing system, combat, XP, item drop entities.
- **lf_npc** — mob framework + AI (wander/chase/flee, grid A* pathfinding), spawning rules, villagers with schedules + trading.
- **lf_client** (replace `dummy()`) — game session, input mapping, egui HUD + all screens (inventory, crafting, chest, furnace, pause, settings, title, death, quest log), key rebinding, EN + PT-BR localization.
- **lf_server** (replace `dummy()`) — authoritative world simulation; singleplayer runs it in-process; dedicated binary exposes it over network.
- **lf_protocol** — expanded: join/leave, movement snapshots, block interactions, inventory/chat sync, interest management.
- **lf_assets** — procedural texture atlas for every block/item, synthesized audio (kira), localization tables.
- **lf_modapi** — runtime registration of modded blocks/items/recipes into the real registries; parse smelting.toml (currently broken); loads `mods/` at boot.
- **lf_vistest / xtask** — real scene harness + golden images; `cargo xtask vistest|screenshot|package`.
- **lf_story / lf_chronicle** — unchanged APIs, wired to live gameplay events.

## Definition of done (base game)
New player can: launch via title screen → create a world → survive nights, mine ore with correct tool tiers, craft/smith gear, cook food, fight mobs and the Null Knight, explore structures and biomes, trade with villagers, complete quests, hear sound/music, save/quit/resume — and optionally host/join a multiplayer session — with mods loading on top, at 60 FPS, packaged installers green in CI.

## Risks & mitigations
- **wgpu/surface complexity for offscreen + transparency** → spike in P0 before depending on it.
- **Physics/AI edge cases** → unit-test tables for collision + pathfinding from day one.
- **Content volume (100+ blocks/items)** → everything data-driven (TOML registries), code stays small; catalog tests enforce consistency.
- **Multiplayer divergence** → single authoritative server sim reused by singleplayer from P9 onward.
- **Art/audio without assets** → procedural textures + synthesized audio keep the repo self-contained (consistent with lf_assets today).

## Suggested execution order
Strictly P0→P11; each phase = multiple verified loops (code + tests + real screenshot + honest STATE update). P0–P4 yields a playable survival sandbox quickly; P5–P8 make it "the whole game"; P9–P11 complete multiplayer, modding, and shipping.
