Nine phases (P12–P20). Each lands working code, keeps `cargo test --workspace` green, smoke-tests the binary, and adds screenshot scenes to the vistest suite with pixel-analysis proof. Nothing is marked done that isn't verifiable.

- **Clouds**: translucent drifting noise-based cloud layer at y≈160 in the transparent pass.
- **Sun/moon billboards + stars** rotating with the day cycle; **underwater fog/tint** when the camera is submerged.
- **Weather**: clear/rain/snow cycle (snow in cold biomes), particle systems around the player, sky darkening in storms.
- World types (normal/superflat/amplified) selectable on the title screen.
- *Proofs:* biome-census test (≥30 biomes occur in a sampled world), "biome_montage" scene, "clouds_weather" scene (cloud layer + rain verified by pixel bands).

## P18 — Ray tracing: compute voxel path tracer (the graphics pillar)
Hardware RT isn't exposed in wgpu 24; the honest fast path is GPU-compute voxel DDA:
- Voxel clipmap: 128×64×128 block-id 3D storage texture around the player (rebuilt on edits).
- WGSL compute: DDA primary rays, **soft sun shadows** (jittered multi-sample), **1-bounce GI** (cosine secondary rays sampling sky + emissive torches), fog, sky gradient, **temporal accumulation** (progressive; resets on camera/world change).
- Composite → tonemap → swapchain, HUD on top; **R toggles** raster ↔ path-traced; headless `render_pathtraced_to_png` for vistest.
- Smooth per-vertex AO in the raster path (the deferred P3 item).
- *Proofs:* "raytraced_shadows" (pixel-verified penumbra gradient at shadow edges), "raytraced_night" (torch color-bleed onto adjacent surfaces), raster-vs-RT side-by-side scene.
