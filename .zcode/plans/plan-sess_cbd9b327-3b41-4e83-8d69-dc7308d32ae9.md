# P21 — Proper menus, animations, HUD rebuild & real settings (incl. ray tracing)

## 1) UI kit (`ui_kit.rs` in lf_client) — the "tools to create a good UI"
- **Theme**: shared palette (gold accent, panel/背景 tones, status colors) + `title_glow` pulsing variant.
- **Easing library**: `ease_out_cubic`, `ease_out_back`, `ease_in_out` + a `Reveal` tracker (duration + delay, dt-stepped, restartable) for staggered entrance animations — all unit-tested.
- **Animated widgets**: `menu_button` (hover glow via `animate_value_with_time`, left accent bar sweep, press spring, fade+slide label on reveal), `slide_panel` (fade+rise container), `toggle` (animated knob switch), `setting_slider` (accent fill + monospace readout), `section_header` (underline sweep).
- **Painted HUD glyphs**: `paint_hearts` / `paint_hunger` draw vector hearts/drumsticks with the egui painter — replaces the unicode glyph row that renders as font boxes.

## 2) Real settings that drive the engine
- Expanded persisted `Settings`: **Video** (FOV, view distance → streaming radius, clouds on/off, weather particles, RT mode `Off | Captures | Live`, RT internal scale), **Audio** (master/SFX/music volumes — persisted now, consumed by the future kira pass), **Gameplay** (sensitivity, invert-Y, show-FPS), plus **Quality presets** (Low/Med/High mapping to the above). Stored inside the existing world save (settings.toml-free, round-trip test).
- Settings screen with tabbed sections using the kit; pause menu links to it; changes apply live (view radius feeds the streamer, FOV feeds the camera, clouds/particles gate the atmosphere batches).

## 3) Live ray tracing (the RT settings made real)
- Refactor `lf_engine::pathtrace` into a persistent `Pathtracer` (device/pipeline/voxel+accum textures created once, `render_frame(...)` reusing them) — no per-frame resource churn.
- `RT mode = Live`: each frame (at the configured internal scale, e.g. 200×150) renders a path-traced view uploaded as an egui texture shown fullscreen behind the HUD; `Captures` keeps the current R-key behavior; `Off` is pure raster. The voxel clip re-uploads when the player crosses blocks or edits.

## 4) Animated title & pause menus
- **Title**: while `UiOpen::Title`, the world camera slowly orbits spawn (day cycle running, weather visible) as a live 3D background; logo with pulse glow + subtitle fade; staggered `menu_button`s (Play, Multiplayer w/ transport label, New Normal/Superflat/Amplified, Settings, Quit) with per-button Reveal delays; version footer.
- **Pause**: dark vignette overlay, `slide_panel` card animating in, kit buttons (Resume / Settings / Save & Quit), keybind cheatsheet.

## 5) HUD rebuild
- Painted hearts + hunger (kit glyphs), real **XP progress bar** with level chip, hotbar centered with animated selection highlight + hovered-slot name tooltip, top-left info line (clock, weather, transport, FPS when enabled), mining/bow-charge bars restyled with accent fill; chat overlay unchanged.

## 6) Proofs & tests
- New vistest egui scenes: `menu_preview` (title UI with buttons visible), `pause_preview`, `settings_preview` — pixel-verified (button frames/glow colors present, tab labels render).
- Unit tests: easing curves, Reveal step/delay/clamp, Settings save round-trip incl. RT mode, quality preset mapping.
- Full suite green + game smoke test + commit.
