```text
Implement NWR-009 only. Deliver an original low-poly, rig-ready NPC base with
resident, worker, and guard clothing/gear variants. Integrate it with current
authoritative NPC brains and positions. Add a minimal deterministic animation
state machine (idle, walk, work, guard) driven by the existing intent/state;

policy at distance, capsule collision, and the declared role readability rules.

characters rather than placeholders.
```
