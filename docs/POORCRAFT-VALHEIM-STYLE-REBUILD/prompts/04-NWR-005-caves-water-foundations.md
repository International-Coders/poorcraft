# NWR-005 — Caves, Water, and Foundations Prompt

```text
Implement NWR-005 only after ordinary surface terrain is migrated and green.

Add sparse local cave/overhang regions with a documented surface extraction
method and shared boundary contract. It must render, collide, save/load, and
stream without cracks, duplicate faces, daylight leaks, or a global volume.
Adapt the existing authoritative river records into a terrain-conforming water
mesh with shore/bank behavior and local remesh after an eligible edit. Preserve
the intentionally simple cached-flow/machine-power model; do not add a
full-world fluid solver.

Add terrain-aware building foundation/support checks. Prove a player can walk a
cave boundary, see no seam, alter a local terrain/flow area, place valid and
reject invalid foundations, and save/reload it. Include before/after windowed
captures and local-work performance evidence. Stop before new art families.
```
