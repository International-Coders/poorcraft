# Tools To Build

These tools are authorized and encouraged.

## Immediate Tools

- `pc3d inspect-ui`: dump current screen and UI layout.
- `pc3d inspect-asset <id>`: dump asset semantics.
- `pc3d seed-preview <seed>`: write map PNG + JSON.
- `pc3d seed-corpus`: write a grid of previews for many seeds.
- `pc3d wireframe <scene>`: write wireframe PNG/OBJ.
- `pc3d perf-capture <scene>`: write frame stats JSON.
- `pc3d interaction-probe <object>`: test use/talk/open/forge/enter.

## Asset Tools

- asset prompt generator;
- asset manifest validator;
- socket visualizer;
- collision/nav overlay;
- LOD silhouette checker;
- semantic-law checker;
- missing-affordance reporter.

## GPU Tools

- marker name dump;
- pass timing CSV;
- RGP/Nsight capture checklist generator;
- UI alpha/color buffer debug view;
- frame generation disable-state logger.

## Rule

Every tool needs at least one test and one sample output path in docs.
