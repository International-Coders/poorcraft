# Acceptance Checklist

WT-002 is done only when all items are true:

- [ ] batch contracts parse;
- [ ] missing required affordances fail tests;
- [ ] generated assets include gameplay metadata;
- [ ] house has enterable door and interior anchor;
- [ ] NPC has talk state and screenshot proof;
- [ ] forge has input/output/heat/workspot and forging proof;
- [ ] inspector exports beauty, wireframe, bounds/anchors, and JSON sidecars;
- [ ] semantic playtest route proves at least three interactions;
- [ ] GPU marker audit lists all major passes;
- [ ] AMD/NVIDIA capture plan exists with official-source assumptions;
- [ ] all JSON sidecars include build hash, seed, viewport, scene, and command;
- [ ] screenshots are pixel-checked and human-inspected.
