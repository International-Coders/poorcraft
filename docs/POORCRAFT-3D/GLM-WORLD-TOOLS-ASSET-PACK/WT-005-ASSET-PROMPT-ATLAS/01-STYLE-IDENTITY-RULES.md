# Style Identity Rules

POORCRAFT 3D needs its own look: readable from first person, charming at
settlement scale, and efficient for a streamed world.

## Visual Rules

- forms are chunky and readable, but not copied from any named game;
- silhouettes must communicate gameplay purpose from 20-60 meters;
- interactive parts are visually emphasized: doors, handles, NPC faces, forge
  work areas, levers, chests, ladders, signs;
- materials are grounded: carved wood, weathered stone, hammered metal, clay,
  cloth, crystal, soot, moss, wet planks, ash, rune glow;
- faction variants use banners, trim, shields, roof shapes, and props rather
  than completely different geometry every time;
- magic is visible through runes, crystals, particles, and emissive accents,
  but still has clear interaction points.

## Source Policy

- no borrowed names, silhouettes, logos, UI, recipes, or exact layouts from
  other games;
- quality references are allowed only as abstract targets;
- every prompt must say "original POORCRAFT 3D design";
- generated assets require provenance notes and acceptance screenshots.
