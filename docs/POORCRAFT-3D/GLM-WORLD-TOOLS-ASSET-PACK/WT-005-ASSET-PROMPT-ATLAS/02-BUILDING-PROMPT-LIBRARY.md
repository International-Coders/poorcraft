# Building Prompt Library

Every building prompt must include door, interior, collision, nav, anchors, and
gameplay purpose.

## Core Prompts

- starter house: original compact timber-and-stone shelter, enterable front
  door, one-room interior, bed nook, chest corner, smoke vent, warm window
  light, collision-simple walls, nav entry.
- blacksmith forge: stone base, timber roof, bellows, anvil workspot, heated
  forge mouth, input crate, output tray, chimney smoke, hot-surface warning.
- tavern: double door, common room, bar counter, rumor board, hearth, rented
  beds upstairs, NPC seating anchors, trade/talk anchors.
- watchtower: climbable ladder, lookout platform, banner, arrow slit, chest,
  guard anchor, fall blockers.
- market stall: cloth canopy, counter, trade crate, hanging sign, merchant
  anchor, price board.
- mine entrance: timber supports, cart rail, lantern hooks, ore pile, cave
  threshold, danger sign, nav entry.
- bridge: walkable planks, side rails, support posts, entry anchors, river
  clearance, repair state.
- town hall: notice board, council table, map table, faction banner, request
  anchor, storage ledger, interior nav.
- shrine: offering bowl, rune sockets, readable iconography, ritual anchor,
  corruption state.
- dock and port crane: boat tie posts, cargo hook, warehouse door, water edge
  blocker, trade marker.

## Variant Axes

- biome: forest, coast, desert, tundra, mountain, swamp, volcanic, corrupted;
- faction: neutral, red banner, blue banner, green guild, mage, industrial;
- condition: new, weathered, damaged, occupied, abandoned, haunted, upgraded;
- scale: hut, village, town, capital, ruin.
