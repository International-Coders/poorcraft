# Acceptance Checklist

WT-005 is done when:

- [ ] all prompt atlas JSON contracts parse;
- [ ] parent world/tools manifest lists every WT-005 file;
- [ ] pc3d_assets guard parses every WT-005 JSON file;
- [ ] prompt libraries cover buildings, NPCs, creatures, machines, items, UI
      sprites, world props, resources, and environmental storytelling;
- [ ] batch rules include deliberate rejection examples;
- [ ] glTF/Blender/import rules cite official source assumptions;
- [ ] UI sprite contract includes alpha, states, contrast, runtime key labels;
- [ ] asset acceptance requires screenshot, wireframe, overlay, JSON sidecar,
      and gameplay affordance proof.
