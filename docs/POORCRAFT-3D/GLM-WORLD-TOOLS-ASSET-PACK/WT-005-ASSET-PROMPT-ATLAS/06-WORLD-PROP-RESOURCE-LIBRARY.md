# World Prop And Resource Library

World props should explain the world and support play.

## Nature

- pine, broadleaf, birch, dead tree, swamp cypress, crystal tree, fungus cap,
  reeds, grass clumps, flowers, herb patches, thorn bushes;
- boulders, cliff rubble, ore veins, clay banks, salt flats, crystal clusters,
  lava crust, ice shards.

## Settlement Props

- crates, barrels, carts, fences, road signs, lantern posts, benches, wells,
  drying racks, hay bales, banners, notice boards, training dummies.

## Dungeon Props

- broken columns, trap plates, locked doors, keys, sarcophagi, ritual bowls,
  wall runes, chains, collapsed beams, loot pedestals.

## Environmental Storytelling

- abandoned camp, broken cart, burnt house, battlefield remains, old shrine,
  miner notes, warning signs, map scraps, faction graffiti.

## Resource Rules

Harvestables need tool tier, yield, depleted state, respawn/decay policy,
biome, rarity, map/quest tags, and screenshot proof.
