# Machine And Item Prompt Library

Machines must communicate how they work.

## Machines

- forge: ore input, fuel input, heat chamber, anvil workspot, output tray,
  blocked/cold/hot/working states.
- kiln: clay input, fuel door, chimney, temperature dial, finished ceramics
  shelf.
- sawmill: log input, blade/gear hazard, plank output, power shaft connection.
- crusher: ore hopper, crushing jaws, dust chute, output bin, jammed state.
- water wheel: axle, paddles, river alignment markers, torque output.
- boiler: firebox, water gauge, pressure gauge, relief valve, pipe ports,
  danger state.
- generator: belt/shaft input, coil housing, output cable, overload light.
- rune altar: crystal socket, offering bowl, rune ring, ritual progress,
  backlash/corruption state.

## Items And Resources

- tools: axe, pick, shovel, hammer, sword, bow, wand, wrench, fishing rod;
- resources: logs, planks, stone, ore, ingots, coal, clay, herbs, crystals;
- loot: coins, relics, scrolls, maps, keys, faction seals, machine parts;
- food: berries, bread, stew, smoked fish, cooked meat, mushrooms.

## Proof Rules

Item icons need inventory screenshots. Machines need input/output state tests.
Resources need harvest/depleted/respawn metadata.
