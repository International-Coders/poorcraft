# Asset Production Brief

WT-005 is the prompt and batch-production layer for assets. It exists because
"make lots of assets" can easily create visual noise instead of a game.

## Production Goal

Create original assets that support:

- first-person survival and construction;
- NPC settlements and faction identity;
- industry, magic, and research progression;
- worldgen variety and landmarks;
- readable HUD/menu/map UI;
- multiplayer/modding-friendly metadata.

## Required Asset Lifecycle

1. prompt;
2. generated source;
3. import manifest;
4. material/LOD/collision/nav/anchor metadata;
5. runtime consumer;
6. screenshot/wireframe/overlay proof;
7. validation report;
8. acceptance or rejection.

No asset skips the lifecycle.
