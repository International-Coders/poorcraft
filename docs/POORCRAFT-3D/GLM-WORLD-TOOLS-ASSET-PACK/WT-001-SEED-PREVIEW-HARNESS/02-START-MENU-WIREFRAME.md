# Start Menu Wireframe

## New World Screen

Top:

- POORCRAFT 3D logo/build line.
- Back button.

Left column:

- World name field.
- Seed field.
- Random seed button.
- Reroll button.
- World type segmented selector.
- Create World button.

Center:

- Preview map panel.
- Spawn marker.
- Optional layer toggles.

Right column:

- Spawn safety: Safe / Risk / Invalid.
- Biome summary.
- Feature hints: river, cave, town, forest, mountain, coast, landmark.
- Seed copy button.

Bottom:

- Prompt strip with exact controls.
- Warning strip for invalid spawn or missing preview.

## Required States

- Empty seed before randomization.
- Random seed generated.
- Typed seed.
- Rerolled seed.
- Invalid preview/spawn.
- Valid preview ready to create.
