# Acceptance Checklist

WT-001 is done only when:

- New World screen exists or is screenshotable as a deterministic UI state.
- Seed field is visible.
- Random seed and reroll are visible.
- Same seed preview is stable.
- Different seed preview differs.
- Preview metadata JSON exists.
- Spawn safety is computed from real worldgen inputs.
- Preview PNG exists.
- Layout JSON exists.
- Pixel-check report exists.
- Tests cover seed resolution, reroll, stability, variety, and spawn safety.
- DEVLOG records screenshot paths and test counts.
