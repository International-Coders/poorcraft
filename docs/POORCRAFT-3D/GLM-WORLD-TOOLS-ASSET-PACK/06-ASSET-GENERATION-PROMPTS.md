# Asset Generation Prompts

Use these prompt patterns for image, GLB, voxel, or renderer-native asset
generation. Generated art must be followed by semantic tagging and proof.

## Structure Prompt Pattern

Create an original POORCRAFT 3D `<structure>` asset for a rugged voxel survival
RPG. It must visibly include `<functional_affordances>`. Style: low-poly,
readable from gameplay camera, original fantasy-industrial craft, no borrowed
franchise shapes. Output must support collision, sockets, and screenshot proof.

Example:

Create an original POORCRAFT 3D blacksmith forge building. It must visibly
include an enterable door, chimney smoke point, forge hearth, anvil socket,
workbench socket, warm light source, and NPC smith standing zone.

## NPC Prompt Pattern

Create an original POORCRAFT 3D `<npc_role>` NPC. It must have readable role
silhouette, face direction, talk stance, idle stance, work prop, faction color
slot, and low-poly gameplay readability.

## Workstation Prompt Pattern

Create an original POORCRAFT 3D `<workstation>` asset with a clear use side,
input area, output area, active state, inactive state, and blocked/failure
visual hint.

## Acceptance Checklist

- Is the function visible?
- Is the player approach direction obvious?
- Is there an interaction anchor?
- Can screenshot proof show it?
- Can a JSON inspector describe it?
- Does it fit the game's original identity?
