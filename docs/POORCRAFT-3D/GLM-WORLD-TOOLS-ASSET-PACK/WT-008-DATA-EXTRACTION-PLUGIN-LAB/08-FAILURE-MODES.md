# Failure Modes

Reject WT-008 work if:

- exporters omit build hash or schema version;
- tools write outside explicit output directories;
- endpoints mutate saves silently;
- bad sample packs pass validation;
- telemetry requires a remote service by default;
- mesh dumps have no material/anchor linkage;
- screenshots and exported state disagree;
- validators hide missing doors, talk anchors, forge outputs, or UI alpha;
- extraction is used as a substitute for fixing gameplay.
