# Owner Demands

The owner wants POORCRAFT 3D to become a broad, free, systemic sandbox RPG, not
a gallery of disconnected generated objects.

Required direction:

- More Markdown and JSON rules for Z-code/GLM.
- Way more assets, but with gameplay semantics.
- A real start menu with random map generation like the old game.
- Seed entry, random seed, world preview, and map preview.
- GPU vendor improvement planning for AMD and NVIDIA.
- GLM must take screenshots, wireframe captures, UI layout dumps, asset info,
  performance data, and gameplay state dumps.
- GLM may create tools, mods, local plugins, or MCP-style inspectors to extract
  everything needed from the game.
- Generated assets must be built from a game perspective.

Examples:

- A house needs a door the player can enter.
- An NPC needs a talk interaction.
- A forge needs a forge/smithing interaction.
- A chest needs storage.
- A mine needs ore, collision, and extraction.
- A farm needs crops that grow and can be harvested.
- A town marker needs NPCs, services, and map identity.

This pack should make it hard for future agents to create pretty but useless
assets.
