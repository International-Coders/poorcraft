# Brainstorm: Things The Owner Did Not Explicitly Mention

Future GLM sessions should consider these, but only when they can be proven.

## World Feeling

- Weather fronts visible in preview and gameplay.
- Roads between settlements.
- Bridges that actually cross water.
- Boats with boarding points.
- Caves with entrances, darkness, loot, and exits.
- Ruins with readable history.
- Landmarks that appear in map and horizon.

## Social RPG

- NPC bark lines.
- Dialogue choices.
- Reputation consequences.
- Hire/follow/dismiss.
- Trade inventory.
- Work assignment.
- Crime/witness memory.

## Survival

- Shelter warmth.
- Food freshness.
- Sleep/rest.
- Injury states.
- Tool wear.
- Carry weight.

## Craft And Industry

- Recipe discovery.
- Workstation upgrades.
- Power networks.
- Fluid pipes.
- Item belts.
- Heat/pressure safety.
- Failure states with visible effects.

## Strategy Layer

- Realm map.
- Faction borders.
- Patrol routes.
- Town growth.
- Diplomacy states.
- War banners and army markers.

## Accessibility

- UI scale.
- Colorblind-safe status colors.
- Subtitle/log panel.
- Hold/toggle sprint.
- Mouse sensitivity and invert Y.
- Reduced motion.

## Proof Features

- Before/after screenshot montage generator.
- Automatic stale-build detection.
- Screenshot diff reports.
- Asset semantic coverage report.
- Seed diversity dashboard.
