# Commit And Bookkeeping

Every completed job must leave a trail a fresh agent can trust.

## Update

- `STATE.md`: loop number, milestone, last_done, next_task, tests.
- `BACKLOG.md`: checked item or new open item.
- `CHANGELOG.md`: short shipped summary.
- `DEVLOG.md`: what, how, evidence, deferrals.
- relevant WT pack docs when a contract changes.

## Stage

Stage only files from the current job. Leave unrelated dirty files untouched.

## Commit Message

Use a concrete message:

- `Implement WT-001 seed preview harness`
- `Add WT-003 observatory state export`
- `Add first semantic asset batch`

## Push

Push to the configured remote. If push fails, report it honestly.
