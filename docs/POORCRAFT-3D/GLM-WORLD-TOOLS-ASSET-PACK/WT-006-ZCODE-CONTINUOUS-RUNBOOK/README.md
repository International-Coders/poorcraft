# WT-006 Z-code Continuous Runbook

This sub-pack turns the earlier WT packs into an operating manual for GLM/Z-code
to keep developing POORCRAFT 3D without drifting into vague planning. It is a
machine-readable and human-readable runbook for selecting tasks, implementing
them, generating proof, handling failure, committing honestly, and continuing.

The runbook exists because the owner wants constant forward motion, screenshots,
wireframes, game data, and playable semantics. GLM must not stop at "looks
good" or "should work."

## Files

- `PROMPT_TO_GLM.txt` - paste this into Z-code before a long coding session.
- `00-OPERATING-LOOP.md` - the required loop.
- `01-TASK-SELECTION.md` - how to choose the next job.
- `02-PROOF-FIRST-DEVELOPMENT.md` - proof gates before success claims.
- `03-FAILURE-RECOVERY.md` - what to do when screenshots/tests fail.
- `04-COMMIT-AND-BOOKKEEPING.md` - logging, staging, commit, push rules.
- `05-SPRINT-CARDS.md` - concrete first sprint cards.
- `06-NO-EXCUSES-LAWS.md` - short rules to keep beside Z-code.
- JSON contracts for the runbook manifest, operating loop, task priority,
  proof gates, failure recovery, sprint cards, evidence bundle, and completion
  audit.
