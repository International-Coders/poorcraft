# No-excuses Laws

Keep this beside the editor.

- If the mouse is broken, fix the mouse before polishing art.
- If Escape crashes, fix Escape before adding features.
- If a screenshot is missing, the visual claim is not proven.
- If a wireframe is missing, the mesh claim is not proven.
- If JSON state is missing, the interaction claim is not proven.
- If a house has no enterable door, reject it.
- If an NPC cannot talk, reject it.
- If a forge cannot forge, reject it.
- If a seed preview is not deterministic, reject it.
- If an optimization has no before/after data, reject it.
- If a task cannot be proven, split it smaller.
