# Task Selection

Use this priority order unless the owner gives a newer direct order.

1. Broken playability: mouse, Escape, menus, crashes, unreadable HUD.
2. WT-001 seed preview: New World random seed/map preview and metadata.
3. WT-003 observatory: screenshot, wireframe, state export, input replay.
4. WT-002 semantic asset factory: house/NPC/forge/chest/resource route.
5. WT-005 first accepted asset batch: UI sprites and core semantic assets.
6. WT-004 first feature slice: settlement/NPC or industry/magic vertical slice.
7. GPU marker/perf capture gates.
8. Mod/multiplayer/Steam readiness slices.

## Pick Criteria

Choose a task only if you can name:

- files to edit;
- runtime behavior to change;
- test to run;
- screenshot or JSON evidence to write;
- exact acceptance gate.

If you cannot name the evidence, split the task smaller.
