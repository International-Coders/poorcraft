# WT-004 Feature Expansion Matrix

This sub-pack turns "brainstorm everything not mentioned" into a structured
feature backlog for Z-code/GLM. It covers world generation, survival, NPCs,
factions, settlements, industry, magic, quests, UI/HUD, multiplayer, Steam,
modding, accessibility, performance, and proof gates.

The rule remains the same: no feature is real until it has runtime behavior,
player-facing UX, data exports, screenshots, tests, and a next-step owner gate.

## Files

- `PROMPT_TO_GLM.txt` - paste this into Z-code for WT-004.
- `00-FEATURE-BRIEF.md` - purpose and constraints.
- `01-WORLDGEN-AND-SEED-FEATURES.md` - terrain, map, seed, biome, water,
  cave, route, and preview features.
- `02-NPCS-FACTIONS-SETTLEMENTS.md` - people, towns, diplomacy, schedules,
  armies, economy, and empire features.
- `03-INDUSTRY-MAGIC-TECH-PROGRESSION.md` - crafting, machines, electricity,
  magic, research, automation, and late-game branches.
- `04-SURVIVAL-COMBAT-EXPLORATION.md` - first-person survival, combat,
  dungeons, travel, hazards, bosses, and rewards.
- `05-UI-HUD-MENUS-ACCESSIBILITY.md` - start menu, HUD, map, controls,
  settings, accessibility, and localization.
- `06-MODS-MULTIPLAYER-STEAM.md` - mod/plugin contracts, server flows, Steam
  readiness, dedicated server tools, and save migration.
- `07-TOOLS-AND-PROOF-GATES.md` - screenshot, observatory, perf, asset, seed,
  and route proof gates.
- `08-ZCODE-SLICES.md` - ordered implementation slices.
- `09-ACCEPTANCE-CHECKLIST.md` - done criteria.
- `10-FAILURE-MODES.md` - ways broad feature work becomes fake.
- JSON contracts for feature backlog, worldgen, NPC/faction, industry/magic,
  UI/HUD, survival/combat, quests/story, multiplayer/Steam, modding/tools, and
  proof gates.
