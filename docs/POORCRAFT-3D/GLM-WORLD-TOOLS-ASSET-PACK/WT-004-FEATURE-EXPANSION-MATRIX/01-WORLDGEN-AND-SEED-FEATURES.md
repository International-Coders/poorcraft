# Worldgen And Seed Features

The start menu must make the world feel alive before the player clicks Create.

## Seed And Preview

- random seed button;
- typed seed field;
- seed hash display;
- map preview;
- biome summary;
- spawn safety;
- nearby structure hints;
- resource hints with uncertainty;
- world type controls;
- same seed stability test;
- different seed variety test.

## Terrain And Biomes

- mountains, valleys, plains, coasts, islands, deserts, wetlands, tundra,
  forests, volcanic fields, magical corruption zones;
- caves with entrances, underground lakes, ruins, ore strata, monsters,
  traversal hazards;
- rivers with flow direction, crossings, docks, water wheels, floodplains;
- roads and trails connecting settlements, ruins, mines, ports, shrines;
- landmark silhouettes visible from distance.

## World History

- seed-generated kingdoms, ruins, wars, trade routes, disasters, myths;
- old roads, abandoned mines, battlefield markers, sunk ships, lost temples;
- NPC/faction memory seeded from world history;
- map labels unlocked through exploration, not all visible immediately.

## Proofs

- preview metadata agrees with generated world;
- spawn is safe and near early resources;
- routes from spawn to first landmarks are traversable;
- biome colors and names match sampled tiles;
- screenshots prove preview, generated terrain, and observatory data agree.
