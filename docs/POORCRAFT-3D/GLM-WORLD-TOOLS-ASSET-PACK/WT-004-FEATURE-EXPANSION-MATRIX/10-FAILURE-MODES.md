# Failure Modes

Reject broad feature work if:

- the backlog is just a wishlist with no proofs;
- features lack player stories;
- systems have no data model;
- visuals have no screenshot gates;
- assets ignore semantic interaction laws;
- worldgen ignores deterministic seeds;
- UI features cannot be clicked by replay;
- multiplayer diverges from singleplayer rules;
- modding accepts broken content silently;
- performance claims have no marker/perf evidence;
- deferrals are hidden instead of written down.
