# UI, HUD, Menus, And Accessibility

The UI must make the alpha playable before it tries to be beautiful.

## Front End

- title screen with visible build hash;
- New World with seed preview;
- Load World with save metadata;
- Settings with graphics/input/audio/accessibility tabs;
- pause menu that never crashes on Escape;
- confirmation for destructive actions.

## HUD

- crosshair, prompt, health, stamina, food, hotbar, selected tool;
- interaction text for talk/open/forge/harvest/build;
- warning states: low health, cold, hunger, danger, blocked action;
- minimap/map markers once worldgen supports them.

## Accessibility

- rebinding;
- UI scale;
- readable contrast;
- hold/toggle options;
- reduced motion;
- subtitles/captions when audio exists;
- colorblind-safe map markers;
- localization-ready strings.

## Proofs

- all screens screenshot at 1280x720 and 1501x801;
- no clipped controls;
- mouse clicks work;
- Escape behavior is deterministic;
- UI layout JSON matches screenshots.
