# NPCs, Factions, And Settlements

NPCs must not be walking decorations. Settlements must not be static props.

## NPC Systems

- identity, name, role, faction, home, schedule, current need;
- talk, trade, follow, work, flee, fight, report, remember, request help;
- relationship, reputation, fear, trust, debt, loyalty;
- dialogue state visible in UI and exportable in observatory JSON;
- NPC routes that respect doors, interiors, workspots, and danger.

## Settlement Systems

- town hall, homes, workplaces, storage, market, defenses, roads;
- population, food, wood, stone, ore, gold, morale, safety;
- jobs: farmer, miner, builder, guard, trader, healer, scholar, smith;
- construction requests and player-built upgrades;
- visible growth over time, not only numeric counters.

## Faction And Empire

- faction identity, colors, banners, leaders, relations, claims;
- diplomacy, trade, raids, alliances, tribute, reputation gates;
- armies with supplies, morale, movement, siege needs;
- player can found, join, betray, or fight factions.

## Proofs

- talk route opens dialogue;
- worker reaches a workspot;
- guard reacts to threat;
- settlement consumes resources and produces output;
- faction marker appears on map and exports ownership.
