# POORCRAFT 3D Devlog — October 2026

## 2026-10-05 — P0-001: packaged-build audit and workspace consolidation

Problem:
The playable build had a strong menu but an unclear first session, a river
that could render beyond its terrain, large geometry intersecting the spawn
view, an empty pack beside a permanently populated build palette, and too many
unrelated letter-key actions. The repository also retained about 36 GB of
regenerable Cargo output across the current and preserved projects.

Change:

- created `CURRENT-PLAN.md`, making the playability reset the active execution
  order and retaining the older Beta 0.2 expansion plan as historical scope;
- added `poorcraft3d/README.md` as the current workspace front door;
- introduced this monthly P3D log and separated it from the legacy root log;
- corrected the format-version test so it derives newer/older values from the
  supported version instead of assuming world version 1;
- removed duplicate Make target definitions, added `make p3d-clean`, and made
  package stamps disclose dirty source trees;
- corrected the nested `.gitignore` paths;
- removed only generated Cargo caches and an empty accidental nested Git
  directory after verifying their contents.

Verification:

- Mounted `poorcraft3d/dist3d/poorcraft3d-macos.dmg` read-only and launched
  `POORCRAFT3D.app`.
- Played from title screen into the existing world; opened Pack and Crafting,
  walked along the river, and tested the current dig input.
- Packaged rebuild route: 191 frames, p50 16.65 ms, p95 21.13 ms, average
  55.5 fps; save/reload retained one constructed block.
- Packaged water route: 56 frames, p50 9.07 ms, p95 11.96 ms, average
  114.8 fps; the route passed its old coverage/remesh checks while the image
  still showed unsupported water at the horizon.
- Packaged UI route: 13 captures and layout checks passed.
- Initial `cargo test --workspace` found one failing core test:
  `header::tests::p3d002_refuses_unknown_versions_per_section`; it expected
  world support 1 after the runtime moved to world version 2.
- Final `cargo test --workspace`: 738 passed, 0 failed. This includes the slow
  GPU, world-generation, save, navigation, and city/NPC/quest integration
  suites.
- Cleaned both Cargo targets after verification: 749,239 generated files and
  74.8 GiB cumulative were removed. The full test run had expanded the caches
  beyond their roughly 36 GB starting size. Final repository size is 1.9 GB;
  current `poorcraft3d/` is 126 MB and Git history accounts for 1.6 GB.

Runtime evidence:

Performance:
The packaged build remains viable on the owner's Intel machine. The reset sets
60 fps as the first-session floor and treats existing frame times as budgets,
not permission to add unbounded content.

Known debt:
The current visual harness can pass a scene that is visibly wrong. River
support, spawn occlusion, and cave-camera validity gates are still required.
The control and crafting redesign is planned but not implemented in this card.
