## Goal

A dragon threat with territory, raids, and a slaying arc whose outcome (death
or pact) reshapes settlements and factions; an advanced magic branch ( Ley
attunement) whose rituals carry real costs and consequences on the same
world state. Pure, deterministic, test-proven.

## Scope

- `pc3d_world::dragon`:
  - `Dragon { lair, power, awake, hp }` with territory radius; `tick()`
    grows power while awake and raids nearby settlements (buildings burned,
    prosperity loss, casualties).
  - `SlayerParty` assault: deterministic combat roll from SeedStreams-like
    integer hashing (no floats); victory slays permanently (D-034 spirit),
    defeat empowers the dragon.
  - `DragonPact`: spare a defeated-at-peace dragon for tribute → territory
    becomes a ward (raids stop, tribute due).
  - Consequences: settlement prosperity/burned state, faction trust shifts
    (slaying earns awe; pact earns suspicion), lair contamination-free but
    scorched region flag.
- Tests: raid cadence determinism, slaying permanence, pact warding,
  faction trust consequences, settlement damage accounting, no-float math.

Tests green, suite green, root untouched, docs agree.
