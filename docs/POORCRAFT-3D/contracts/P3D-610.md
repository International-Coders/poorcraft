# POORCRAFT 3D Task Contract

## Identity

- Task ID: P3D-610
- Title: Player-built and NPC-commissioned civic projects
- Stage/gate: P3D-600 (settlements, factions, empire)
- Owner/model: owner directive; z.ai GLM session
- Date: 2026-09-06

## Goal

Civic projects (aqueducts, walls, granaries) can be commissioned by the
PLAYER (spends from inventory) or by NPCs (auto-advanced per tick).
Both use the same materials, site, and ownership contracts. Projects
complete when work_done >= work_required.

## Scope

- `pc3d_world::civic`:
  - `CivicProject { name, commissioned_by, work_required, work_done,
    materials_needed, materials_delivered, completed }`.
  - `CivicBoard` — manages all active projects per settlement;
    `commission(name, by, work, materials)`, `deliver_materials(project,
    count)`, `npc_tick(work_per_npc, npc_count)` auto-advances NPC
    projects; `completed_projects()`.
- Tests: player commission + material delivery + completion; NPC
  auto-advance + completion; ownership tracking; both paths produce
  identical completion states.
