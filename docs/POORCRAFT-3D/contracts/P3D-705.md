## Identity

- Task ID: P3D-705

- Stage/gate: P3D-700 (advanced paths)

## Goal

Ideology-flavored castle kits: each ideology brings signature modules
(Arsenal for Conquest, Mint/Warehouse for Commerce, Cathedral/Reliquary for
Faith, Forum/Watchpost for Liberty, Vault/Lookout for Isolation), a kit
manifest, and a kit-aware capital planner that places core + signature
modules deterministically on real terrain, plus a faction kit table tying
ideology to preferred law and posture. Pure and test-proven.

## Scope

- `castle.rs`: add the ten signature ModuleKind variants (names,
  footprints); expose `footprint_fits`.
- New `kits.rs`:
  - `kit_modules(Ideology) -> Vec<ModuleKind>` (two signatures each).
  - `kit_manifest(Ideology) -> Vec<CastleModule>`.
  - `FactionKit { ideology, preferred_law, modules }` and `kit_for(Ideology)`.
  - `plan_capital_kit(gen, center, ideology) -> CastleLayout` — core plan
    plus signature modules at terrain-valid, non-overlapping, deterministic
    sites.
- Tests: manifest sanity (unique kinds, positive footprints), kit
  distinctness across ideologies, deterministic identical layouts,
  non-overlap + terrain-validity of placed kit modules, plan_capital
  regression unchanged.

## Done when

Tests green, suite green, root untouched, docs agree.
