## Goal

The pure protocol layer a dedicated server needs: a reliable channel with
sequence numbers, cumulative acks + range bitfield, gap-buffered in-order
delivery and resend; interest-filtered versioned snapshots of replicated
state with stale-snapshot rejection; client mirrors proven to converge to
host values. No real sockets — the transport adapter arrives with 803.

## Scope

- New `pc3d_world::replicate`:
  - `ReliableChannel`: `send(payload) -> seq`, `receive(seq, payload)`
    (in-order application, out-of-order buffered), `ack(seq, bits)`,
    `needs_resend()`.
  - `Snapshot { tick, origin, radius, values: BTreeMap<u64, [i64; 4]> }`.
  - `interest_snapshot(settlements, player_region, radius, tick)` — only
    in-radius settlements replicated.
  - `Mirror::apply(snapshot)` — rejects stale ticks, converges values.
- Tests: ordering/gap delivery, ack bookkeeping + resend, mirror
  convergence to host values, interest radius filtering, staleness.
