## Goal

The world knows what to stream and refuses to drown: concentric interest
rings (the blueprint's 0–96 / 96–320 / 320–1024 m tiers) map a viewer
position onto bounded patch sets, a fixed-capacity work queue admits work
with a visible backlog (a teleport cannot create unbounded work), and
interest diffs produce deterministic load/unload plans.

## Current truth

- `pc3d_world` has the patch hierarchy (P3D-101), generation + atlas
  proofs (P3D-103/104); `pc3d_core` has the profiler counter vocabulary
  (P3D-004). No streaming logic exists.

## Scope

### Must change

- `pc3d_world::stream`:
  - `TIER_FULL/TIER_LOD/TIER_MACRO` radius constants (blueprint proposal
    values: 96/320/1024 m) and `Tier` enum; radii are constants in the
    scales/one-place tradition, benchmarked later (P3D-201+).
  - `interest_patches(viewer: WorldPos, tier) -> Vec<PatchCoord>`: patch
    columns (y=0) whose centers lie within the tier ring around the
    viewer, strictly ascending, capped by MAX_QUERY_PATCHES semantics.
  - `BoundedQueue<T>`: fixed capacity, `push` returns
    `Admitted | RejectedFull(item)` (never panics, never grows past
    capacity, nothing silently dropped), `pop`, `len`, and cumulative
    counters (pushed/admitted/rejected/popped) — the backlog is always
    visible.
  - `interest_diff(previous, current) -> (to_load, to_unload)`: sorted,
    deterministic, disjoint set difference.
- Tests: ring membership (boundary distances, far/negative viewers);
  ascending order + no duplicates; queue capacity, FIFO order, counter
  honesty; THE teleport scenario (large diff → queue admits only its
  capacity per wave, re-push is gradual, rejections accumulate across
  waves and every rejected item stays held by the caller — nothing lost,
  counters account for every push); diff determinism; unload
  correctness; empty-set edges.

### Explicit non-goals

- No actual mesh jobs, no worker threads, no async (P3D-201+ fills the
  queues).
- No persistence interaction, no network interest messages (P3D-802).
- No LOD selection logic beyond tier membership (P3D-206).

## Contracts and invariants

- deterministic behavior: sets and diffs are sorted vectors of PatchCoord;
  identical inputs → identical outputs.
- authority/ownership: `pc3d_world::stream` owns interest math; the
  runtime/host consumes it.
- save/load behavior: n/a.
- network behavior: n/a.
- performance budget: interest computation O(touched patches) capped;
  queue ops O(1).
- player-visible result: flight/teleport stays smooth — bounded work per
  frame with an honest backlog, never a freeze.
