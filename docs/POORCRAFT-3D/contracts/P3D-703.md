## Goal

Fission reactors with explicit safety systems (control rods, automatic SCRAM,
containment integrity), radiation that leaks on meltdown and contaminates the
world (settlement prosperity consequences), and a hard per-world reactor cap
(D-018).

## Scope

- `pc3d_world::nuclear`:
  - `Reactor { site, fuel_milli, control_pct, temp_milli, integrity, scrammed }`
    with `tick()` — burn → heat → temperature; control rods throttle;
    over-temperature triggers automatic SCRAM (rods full in, output 0,
    temperature falls); meltdown when heat outruns containment: integrity
    damage, radiation leak into the contamination map.
  - `Contamination` map (RegionCoord → milli-dose) with decay.
  - `prosperity_penalty(settlement_region)` — consequence within radius.
  - `MAX_REACTORS` world cap; `NuclearProgram::add` refuses beyond it.
- Tests: power curve vs rod insertion, SCRAM safety, meltdown leak +
  decay, settlement consequence gradient, cap enforcement, determinism.

## Done when

Tests green, suite green, root untouched, docs agree.
