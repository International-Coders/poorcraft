## Goal

A seed produces a coherent world: macro elevation/climate fields per 256 m
region that correlate across neighbors (geography, not confetti), a biome
table that reads as terrain (oceans low, mountains high, wetlands humid),
and any 16 m patch regenerating its 1 m cells deterministically from the
global height function — same seed, same patch, identical bytes and hash.

## Current truth

- `pc3d_core::seed` provides SeedStreams (terrain label) + SplitMix64.
- `pc3d_world` has the spatial hierarchy (P3D-101) and `pc3d_save` persists
  opaque patch payloads (P3D-102). No generation exists yet.
- D-016 requires biome/hydrology-driven coherence; rivers are P3D-301, so
  this task builds the fields and the documented extension point, not the
  river graph.

## Scope

### Must change

- `pc3d_world` gains a `pc3d_core` dependency (shared seed contracts — the
  execution prompt requires shared contracts, not duplicated RNGs) and a
  `gen` module:
  - `MacroField { elevation_m: i32, temperature: u8 (0..=100), humidity:
    u8 (0..=100) }` per RegionCoord from multi-octave value noise over the
    region lattice (bilinear + smoothstep between lattice hashes), so
    neighbor regions correlate.
  - `Biome` enum (Ocean, Coast, Plains, Forest, Wetland, Highlands,
    Mountains, SnowPeaks) chosen by field thresholds; `biome_of(field)`.
  - Global height function `surface_height_mm(world_x, world_z)` — bilinear
    over region elevations, PLUS detail noise so patches are not flat
    ramps; this function is the immutable procedural base (blueprint
    layer 1).
  - `regenerate_patch(seed, PatchCoord) -> PatchCells`: 16³ cells of
    `CellMaterial` (Air/Soil/Grass/Sand/Rock/Snow) from the height
    function + macro biome surface material; `patch_hash(seed, coord)`.
- Tests: same-seed determinism (cells + hash identical); seed sensitivity;
  biome/field coherence (oceans only at negative elevation, SnowPeaks only
  at high cold elevation, Wetland requires high humidity); neighbor-region
  elevation continuity bounded; height continuity across patch borders
  (structural: the function is global — assert sample columns match
  either side); regeneration independent of any other patch.

### Explicit non-goals

- No caves/overhangs density fields (P3D-203), no rivers/watersheds
  (P3D-301), no resources/ores/strata depth, no meshing, no sites.
- No persistence integration yet (P3D-102 stores opaque payloads; wiring
  them together is a later composition task).

## Contracts and invariants

- deterministic behavior: every value derives from (seed, integer coords)
  through FNV/SplitMix — no floats in storage, f32 only inside noise
  interpolation, no time/env input.
- authority/ownership: `pc3d_world::gen` owns world content; the height
  function is THE shared answer (mesh/collision/water later query it).
- save/load behavior: regeneration is the save — untouched patches are
  never stored (blueprint layer 1); hashes make that verifiable.
- network behavior: n/a.
- performance budget: one patch = 4096 cells, O(patch) work, no global
  scans; region fields are cheap lookups + bounded noise octaves (≤4).
- player-visible result: none rendered yet; but the same start area greets
  the player every run of a seed.
