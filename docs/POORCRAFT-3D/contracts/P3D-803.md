## Goal

The session layer under multiplayer: lobbies with a host-chosen member cap
(D-029), deterministic invite/accept lifecycle, deterministic host
migration, and a `Transport` trait with an in-memory loopback
implementation that routes sequenced messages — the future Steam SDK
transport implements the same trait, so no gameplay code changes.

## Scope

- New `pc3d_world::session`:
  - `Transport` trait + `LoopbackTransport` (deterministic in-memory
    queues, per-peer outboxes).
  - `LobbyManager`: create (host-chosen cap), invite/accept/decline,
    join cap enforcement, leave, host migration on host leave (lowest
    remaining member id).
  - `Session` glue: lobby + transport, `broadcast` fan-out to members.
- Tests: invite lifecycle, cap enforcement, migration determinism,
  loopback delivery + broadcast fan-out, Steam-trait substitutability
  (a fake transport behind the same trait drives the same flows).
