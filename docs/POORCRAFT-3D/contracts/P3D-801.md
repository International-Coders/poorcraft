# POORCRAFT 3D Task Contract

- Task ID: P3D-801

- Stage/gate: P3D-800 (integration & multiplayer)

## Goal

One `SoloHost` owns the deterministic spine (clock, command sequencer,
journal, seed streams) AND every canonical world system (generator, river
flow, settlements, construction, machines, nuclear, dragons) in a single
tick loop: player intents enter as envelopes in canonical (tick, id) order
and every system advances together, bit-identically for the same seed and
command history.

## Scope

- New `pc3d_world::host`:
  - `HostCommand` (Build, RemoveBuild, FeedBoiler, FuelReactor, SetRods,
    SpawnDragon, AssaultDragon).
  - `SoloHost::new(seed)`, `submit(cmd)`, `run_ticks(n)` — per tick:
    apply due envelopes canonically, tick machines + nuclear, on the day
    boundary tick settlements + dragons; journal heartbeats and key
    events (raids, meltdowns); `digest()` over journal + system state.
- Tests: cross-host determinism with REORDERED command delivery, build
  path integrity through the authoritative path, reactor + boiler living
  in one world behind a working SCRAM, dragon raid day landing on the
  settlement through the host loop.

## Done when

Tests green, suite green, root untouched, docs agree.
