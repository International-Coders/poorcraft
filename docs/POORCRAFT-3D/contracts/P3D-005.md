# POORCRAFT 3D Task Contract

## Identity

- Task ID: P3D-005
- Title: First empty-world runtime and a headless smoke path
- Stage/gate: P3D-000 stage capstone
- Owner/model: owner directive "MAKE ALL described in the folder"; z.ai GLM session
- Date: 2026-09-04

## Goal

`poorcraft3d --run` drives a real loop: frames advance the fixed clock,
ticks do honest (empty-world) work, everything is measured, and the run is
fingerprinted — with `make p3d-smoke` asserting liveness headlessly, the
same way `make smoke` guards the original game.

## Current truth

- `pc3d_core` has the full deterministic spine (clock/commands/journal/
  seeds/replay digest) and the profiler (P3D-001..004), 28 tests green.
  The binary answers `--identity`, `--format`, `--baseline` but has no
  loop; nothing runs for more than one shot.

## Scope

### Must change

- `pc3d_core::runtime` — `WorldRuntime`: owns FixedClock, Counters,
  FrameTimes, EventJournal, CommandSequencer, SeedStreams; `new(world_seed,
  profile_name)`; `frame(real_dt_ms)` advances the clock, executes each
  fired tick (empty-world tick: entity-tick counter + a heartbeat journal
  event every `HEARTBEAT_TICKS = 600` with a seed-derived payload), then
  records the frame; `stats()` returns tick/frame/percentile/digest
  numbers; `digest()` is a ReplayDigest over tick + counters + journal.
- `run_headless(world_seed, frames)` — free function driving `frames`
  frames with the deterministic jitter stream (same construction as
  `--baseline`); returns the runtime for inspection.
- Binary: `--run [seconds]` (default 5) runs headless and prints a stats
  line; exit 0 on liveness (ticks > 0, frames as requested, journal
  non-empty).
- Makefile: `p3d-smoke` target running `--run 5` and failing on non-zero
  exit; help text updated.
- Tests: two `run_headless` runs with the same seed produce identical
  digests; liveness invariants; heartbeat cadence; digest changes when the
  seed changes; frame stats tracked.

### Explicit non-goals

- No window, renderer, input, audio, or GPU (a later stage per
  10-BETA-SCOPE-AND-SEQUENCING.md engine-first order).
- No terrain/entities yet — "empty world" is literal; P3D-101+ fills it.
- No persistence of the runtime (P3D-102).

## Contracts and invariants

- deterministic behavior: same seed + same frame count → identical digest,
  byte-identical stats line; the jitter stream is the only time source.
- authority/ownership: `WorldRuntime` is the single owner of the clock/
  counters/journal trio — the shape every later host (solo or dedicated)
  must reuse.
- save/load behavior: n/a (P3D-102).
- network behavior: n/a.
- performance budget: the smoke run (5 s of simulated frames at ~11–33 ms)
  completes in well under a second of real time; no allocation per tick.
- player-visible result: launching `poorcraft3d --run` shows a live loop
  counting ticks — the new game RUNS.

## Verification

- unit/integration tests: runtime determinism, liveness, heartbeat
  cadence, seed sensitivity, stats sanity (p50 between min and max).
- persistence/replay tests: the digest IS the replay fingerprint.
- visual proof scene: n/a.
- smoke or multiplayer test: `make p3d-smoke` (headless, exit-code
  asserted) — recorded in DEVLOG.
- profiling/counter evidence: the run prints p50/p95 and counters from the
  real FrameTimes/Counters.

## Done when

`make p3d-smoke` passes, pc3d_core tests green, root workspace untouched
and green, docs agree. P3D-000 stage complete on success.

  see it tick.
