# POORCRAFT 3D Task Contract

## Identity

- Task ID: P3D-406
- Title: Companion follow/wait/assist/recovery behaviors
- Stage/gate: P3D-400 (movement, entities, NPC foundations)
- Owner/model: owner directive "COMPLETE AT LEAST NEXT 20 steps"; z.ai GLM session
- Date: 2026-09-04

## Goal

A companion follows the player at a lagging distance (nav path per tick
behind them), holds on Wait, ASSISTS by pathing to the player's target
cell, and RECOVERS when left behind (teleport-free catch-up: the follow
path recomputes from wherever the companion actually is) — all
deterministic on the fixed clock.

## Scope

### Must change

- `pc3d_world::companion`:
  - `CompanionCommand { Follow, Wait, Assist { target: CellCoord } }`.
  - `Companion { entity: EntityId, pos: CellCoord, command, path, leg }`
    with `step(gen, player_cell, input)`: Follow — if farther than
    FOLLOW_DISTANCE from the player, path behind them (path recomputed
    whenever the player cell changes or the old path is exhausted);
    Wait — hold; Assist — path to the assist target, then hold there.
    Recovery: because paths recompute from the companion's ACTUAL
    position, being left behind self-heals without teleporting.
  - Path caching keyed by (player cell, target) to avoid re-pathing
    every tick.
- Tests: follow keeps the companion within FOLLOW_DISTANCE+1 after the
  player stops; wait holds position; assist routes to the target and
  holds; recovery after a player jump of 40 cells converges without
  teleport (positions pass through intermediate cells); determinism;
  command switches are immediate.

### Explicit non-goals

- No combat assist mechanics (assist = POSITIONING only), no dialogue,
  no multi-companion formations.

## Contracts and invariants

- deterministic behavior: same command/cell history → same positions.
- authority/ownership: `pc3d_world::companion` owns companion behavior.
- save/load: plain data (persist with the registry).
- performance budget: one nav path per player-cell change, not per tick.
- player-visible result: a companion that follows, waits, assists, and
  never falls permanently behind.
