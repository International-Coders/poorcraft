## Goal

Typed machines (SteamEngine, Generator, Battery) with typed power connections (Mechanical, Electrical, Heat) — machines consume one power type and produce another, with deterministic conversion rates. All pure and test-proven.

## Scope

- `pc3d_world::machines`:
  - `PowerType` (Mechanical, Electrical, Heat).
  - `MachineKind` (SteamEngine, Generator, Battery) with typed inputs/outputs.
  - `Machine { kind, fuel, output }` with `tick(fuel_available) -> output`.
  - `MachineNetwork` — connects machines: steam engine produces Mechanical, Generator consumes Mechanical produces Electrical, Battery stores Electrical.
- Tests: production determinism, type-safe connections, fuel consumption, energy conservation (output ≤ input), network evaluation.
