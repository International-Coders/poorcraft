## Goal

The castle has working defenses: a gate that opens/closes, guards that
patrol and respond to alarms, laws that define allowed/denied actions,
and faction standing that gates access. Witnesses report crimes through
the P3D-405 perception system. All deterministic.

## Scope

### Must change

- `pc3d_world::castle_law`:
  - `GateState { open: bool }` toggled by guards or authority.
  - `Law { kind: LawKind (Theft/Assault/Trespass), severity: u8,
    punishment: Punishment (Fine/Exile/Attack) }`.
  - `Alarm { active, raised_at, tick }` — raising summons guards within
    response radius; guards path to the alarm and clear it.
  - `access_allowed(faction_standing, law_threshold) -> bool` —
    faction standing must meet the law's threshold to enter.
  - Integration: `Witness` from P3D-405 reports crimes; `Alarm` summons
    guards who use P3D-403 nav to respond.

### Explicit non-goals

- No actual NPC pathfinding integration (guards use nav but don't
  physically move yet — P3D-404 NPCs compose later). No combat.
