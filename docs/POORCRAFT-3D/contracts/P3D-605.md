## Goal

Faction relations model trust between factions, diplomacy actions
(alliance/war/trade), quest offers, territorial disputes, and territory
control — all deterministic, test-proven.

## Scope

- `pc3d_world::faction`:
  - `FactionId(u64)`, `TrustLevel` (Allied/Friendly/Neutral/Wary/Hostile).
  - `FactionRelations` — trust matrix between factions, diplomacy
    actions shift trust, territory claims per faction.
  - `Quest { id, faction, kind, target_cell, reward_reputation }` —
    offered by factions, accepted/completed.
  - `Territory { faction, regions: BTreeSet }` — claimed regions.
- Tests: trust shifts, diplomacy state transitions, quest lifecycle,
  territory claims, determinism.
