## Goal

NPCs WITNESS moral events within a sight radius, store them as personal
knowledge (evidence with confidence and age), REPORT knowledge to nearby
NPCs (spreading evidence with decayed confidence), hold faction karma
baselines, and answer a LOCAL REACTION query (disposition toward an
actor) derived from evidence — deterministic, bounded memory.

## Scope

### Must change

- `pc3d_world::perception`:
  - `MoralEvent { actor_id, kind: MoralKind (Theft/Assault/Gift/Help),
    at: CellCoord, tick }`.
  - `Perception::witness(gen-independent, npc_pos, sight_radius, event)
    -> bool` — Chebyshev radius check.
  - `Knowledge`: per-NPC evidence list (event + confidence f32
    1.0→decays with age by KNOWLEDGE_DECAY), `remember(event, conf)`,
    `forget_old(current_tick)`, bounded capacity (drops lowest
    confidence first).
  - `report(knower, listener, event_ref)`: spreads an event to the
    listener's knowledge at REPORT_CONFIDENCE (lower than witnessed).
  - `Karma`: per-faction baseline + per-actor delta from evidence;
    `disposition_toward(actor, faction) -> i32` clamped.
- Tests: witness radius (in/out/boundary); report spread with lower
  confidence; knowledge aging + bounded capacity; karma shifts from
  evidence and baseline clamp; determinism.

### Explicit non-goals

- No pathing changes, no rendering, no UI; reactions are disposition
  NUMBERS (behavioral use is later stages).

## Contracts and invariants

- deterministic behavior: all pure functions of event history.
- authority/ownership: `pc3d_world::perception` owns the model.
- save/load: plain data (persistence with the registry later).
- performance: bounded memory (capacity 32 per NPC).
- player-visible result: witnesses REMEMBER who did what — the foundation
  of faction consequences.
