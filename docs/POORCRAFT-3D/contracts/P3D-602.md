## Goal

A modular castle planner generates a terrain-aware multi-building capital
district: buildings are selected from a MANIFEST (the available castle
kit), placed on walkable terrain near the settlement center, and
connected by roads. The layout adapts to elevation (no building below
sea level, no building on steep slopes) and produces a deterministic,
validatable plan.

## Current truth

- `pc3d_world::settlement_plan` (P3D-601) provides the settlement
  building layout and anchors. `pc3d_world::nav` provides walkability.
  `pc3d_world::gen` provides the height function. No castle-specific
  planning exists.

## Scope

### Must change

- `pc3d_world::castle`:
  - `CastleModule { kind: ModuleKind, footprint: (u8, u8), ports: Vec<Port>
    }` — the modular building definition. `ModuleKind` (Keep, Wall,
    GateHouse, Tower, Barracks, Chapel, Market). `Port` (direction +
    offset) marks where roads connect.
  - `CastleManifest` — the catalog of available modules with placement
    rules (terrain requirements: min elevation, max slope).
  - `CastleLayout` — placed modules on the terrain: `plan_capital(gen,
    center) -> CastleLayout`, placing modules on walkable terrain in a
    deterministic order (Keep at center, walls ring, towers at corners,
    support buildings in remaining slots).
  - `CastleLayout::validate(nav) -> LayoutValidation` — all modules on
    walkable terrain, ports aligned, no overlapping footprints.
- Tests: deterministic layout; terrain adaptation (no module below sea
  level); manifest completeness (all modules have valid footprints);
  port alignment; validation catches overlaps; the capital district is
  larger than a single settlement plan (multi-ring).

### Explicit non-goals

- No 3D block construction (P3D-205 overlay composes later), no
  faction-specific castle variants (P3D-605+), no NPC spawning into
  castle positions (P3D-404 registry).

## Contracts and invariants

- deterministic behavior: same seed + center → identical layout.
- authority/ownership: `pc3d_world::castle` owns the castle kit and
  planner.
- performance: O(modules × footprint cells).
- player-visible result: (later rendered) a recognizable castle district
  with keep, walls, towers, and support buildings.
