## Goal

Measured scale evidence per D-029 ("up to 128 only when the server can
sustain it — no universal claim"): N simulated players each with their own
interest snapshot and reliable-channel traffic run through the host's tick
loop at N = 4, 16, 32, 64, 128; per-player replication cost must be
independent of N (the interest-management law), total tick cost must grow
linearly, and the measured rows are reported — 128 is a claim only if the
rows sustain it.

## Scope

- New `pc3d_world::scale`:
  - `ScaleRow { players, avg_tick_micros, snapshots_per_tick, bytes_per_tick, max_entries_per_player }`.
  - `scale_proof(seed, counts) -> Vec<ScaleRow>` — deterministic player
    placement, interest snapshots + channel traffic per player-tick.
- Tests: per-player snapshot size independent of N, sub-linear total
  growth with generous wall-clock slack, 128-player run sustainable
  under an explicit budget, rows reproducible in structure.

## Done when

Tests green, suite green, root untouched, docs agree.
