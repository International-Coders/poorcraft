## Goal

A soak harness (`pc3d_world::soak`) that runs the integrated host for
many in-game days under a continuous deterministic command stream and
audits the world afterward: bounded journals, clamped aggregates, cooled
reactors, finite machine buffers, digest determinism, and zero drift.
An in-suite soak (40 days) runs with the tests; `--soak DAYS [SEED]`
runs arbitrary-length soaks from the CLI as a player-diagnostic script.

## Scope

- New `pc3d_world::soak`:
  - `run_soak(seed, days) -> SoakReport` — deterministic command script
    (builds, boiler feeding, reactor fueling/rods, dragon events) spread
    across the run.
  - `SoakAudit` — bounds checks (aggregates, contamination, machine
    buffers, reactor temps, journal rate) with reasons.
- CLI: `--soak <days> [seed]` in apps/poorcraft3d.
- Tests: 40-day in-suite soak passes its audit AND bit-identical on
  re-run; a failing audit reports the violated bound.

## Done when

Tests green, suite green, root untouched, docs agree.
